# RSIF Public Examples

## Repository Role

Synthetic example objects demonstrating RSIF-compatible structured technical data.

**Status:** Synthetic examples.

This repository shows how public quantitative CT/DICOM observations can be serialized for documentation and interoperability review. The examples are illustrative, synthetic, and intentionally non-clinical.

## Example Areas

- Spine and vertebral attenuation examples
- Liver and spleen attenuation examples
- Combined multi-region example objects

## Machine-Readable Assets

- Synthetic JSON-LD example objects under the example directories

## What This Repository Is Not

- A production pipeline
- Real patient data
- ROI placement methodology
- Internal validation logic
- Clinical interpretation
- Diagnosis or disease detection support
